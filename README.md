# MiniCode AI — GitHub Pages version

This is a static HTML/CSS/JavaScript conversion of the Gradio notebook supplied for MiniCode AI.

## Publish free with GitHub Pages

1. Create a GitHub account at https://github.com/ if needed.
2. Create a new **public** repository named `minicode-ai`.
3. Upload `index.html` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for deployment. Your site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/minicode-ai/`

No Python server, Gradio subscription, API key, or AI model is required. The program runs in the visitor's browser.

## Features retained

- Addition, subtraction, multiplication, division
- Even/odd number checks and ranges
- Greatest number
- Multiplication tables
- Listing number ranges
- Help and example prompts
- Clear and run controls
- Responsive dark interface

## Important

MiniCode AI uses predefined rules and pattern matching. It is not a machine-learning model or an LLM. The browser version processes input locally and works offline after the page has loaded.
